# Hangar app

The Tauri 2 (Rust) + Svelte 5 source of Hangar. See the [main README](../README.md) for what Hangar is and how to build it.

- `src/` - the frontend (SvelteKit SPA, Svelte 5, TypeScript)
- `src-tauri/` - the Rust side: finding installs, running and following ED's updater, logs, backups, mods
